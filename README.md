# Favorite Pets — React + Bootstrap 5

A beginner React application that shows six pets and filters them by animal type.

## Run in Visual Studio Code

1. Open the project folder in VS Code.
2. In PowerShell, run `npm.cmd install`.
3. Run `npm.cmd run dev`.
4. Open the localhost URL shown.
5. Try searching for dog, cat, bird, or BIRD.

## Files

- `src/App.jsx` — filter state.
- `src/Search.jsx` — search input and Bootstrap table.
- `src/data.js` — pet data, specialties, and image references.
- `src/assets/` — six real photos supplied for the assignment.

Bootstrap 5 styling is loaded from a CDN. A screenshot of the running website is still needed for class submission.
